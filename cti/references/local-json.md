# 本地 JSON 适配

用于离线测试，不调用 MCP。仅支持下列明确格式：

```json
{
  "schema":"cti.table.v1",
  "columns":["标题","Route","UI补充描述","交互描述"],
  "rows":[
    {"标题":"登录","Route":"signin","UI补充描述":"登录表单","交互描述":"原文"},
    {"标题":"客服弹窗","Route":"","UI补充描述":"","交互描述":"原文"}
  ]
}
```

文件作为一个工作表，文档身份使用解析后的绝对路径。列名遵循 sources.md；数组位置只作当前 locator，按标题重新定位。未声明或重复列、重复标题、rows 类型不符、JSON 解析失败均明确报告。不是此 schema 的 JSON 不猜结构、不覆写；需要提供该格式或新增显式适配。

用标准 JSON 解析/序列化读取和改写，保留所有未知字段、非目标行和非目标字段。缺省单元格按空值读取；写回只设置目标「交互描述」字段，不丢弃其他 keys。归一化用于分析，不能直接把精简后的统一快照覆盖原文件。

按 sources.md 比较原值后，对刚读取的完整 JSON 做最小字段更新，UTF-8、ensure_ascii=false。先写同目录临时文件，替换前再核对文件内容哈希，变化则丢弃临时文件并标 conflict；使用文件替换后重读目标值及非目标数据核对。此流程不是跨进程事务，不宣称完全消除并发窗口。不得把目标文件当代码执行。
